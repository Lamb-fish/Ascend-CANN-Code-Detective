# Ascend CANN 代码侦探 · 公开成果

[English](README.en.md) | 简体中文

记录 Ascend CANN「代码侦探」活动中可公开的算子开发成果与学习经验。内容仅在活动结束、规则允许并完成发布审查后加入；目录预留不代表已完成挑战。

## 内容

- [历期成果](challenges/README.md)：第 11～15 期索引和已批准的成果。
- [参与与贡献记录](records/README.md)：GitCode PR、评测、活动及获奖记录。

本仓库不接收进行中活动的代码、原始实验数据或凭据。成果以实际提交为准；评测结果须保留环境、方法和可核验依据。私有开发仓库独立维护，发布流程由开发仓库管理。
